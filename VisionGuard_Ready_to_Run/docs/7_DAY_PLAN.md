# VisionGuard — 7-Day Milestone Plan

| Day | Tasks | Evidence / output |
|---|---|---|
| 1 | Organize labeled images, audit classes, create 70/15/15 split | Dataset folder counts |
| 2 | Resize, normalize, augment, create DataLoaders | Working data pipeline |
| 3 | Build CNN / load pretrained ResNet-18 and replace classifier head | Model summary and trainable layers |
| 4 | Implement forward pass, loss, optimizer, backpropagation, validation | Epoch logs |
| 5 | Train, use TensorBoard, early stopping, and checkpoints | best.pth, last.pth, training curves |
| 6 | Evaluate test set and calculate class metrics and ROC-AUC | JSON, report, confusion matrix, ROC |
| 7 | Run single-image inference, document results, prepare demo | predict.py output, README, presentation |

The 7-day schedule is a milestone guide, not a guarantee that training or dataset preparation will finish within a fixed time.
